# 🤖 ATS Simulator Web

Interface web para análise de CVs com logs em tempo real.

## 🚀 Como usar

```bash
# Instalar dependências
pip install -r requirements.txt

# Rodar
python app.py

# Abrir no navegador
http://localhost:5000
```

## ✨ Features

- 📄 Upload de PDF e DOCX
- 🔍 Engine de parsing com fallback (pdfplumber → PyPDF2 → pdfminer)
- 📊 Análise em 6 dimensões
- 📝 Logs em tempo real
- 🎯 Comparação com múltiplas vagas
